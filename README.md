# CYBER BULLET HELL (スマホブラウザ対応 弾幕シューティングゲーム)

スマートフォンおよびPCブラウザで快適に遊べる本格派弾幕シューティングゲームです。

🌐 **公開URL (GitHub Pages)**: [https://hiyasinnsu.github.io/test_HY_gemini/](https://hiyasinnsu.github.io/test_HY_gemini/)

---

## 🎮 特徴

- **スマホ最優先の快適操作**:
  - 指で自機が隠れない**相対ドラッグ追従**操作。画面上のどこをスワイプしても快適に回避可能。
  - 親指で押しやすい「**BOMB**」ボタン（画面全体消弾＆大ダメージ、敵弾アイテム化）。
  - 精密な弾幕避けができる「**SLOW**」トグルボタン。
  - 自動ショット標準搭載（回避とボムに専念可能）。
  - ピンチズームや不要なスクロール、長押しメニューを完全に防止（`touch-action: none`）。
- **本格的な弾幕シューティング（STG）要素**:
  - 自機中央の赤いコア（極小当たり判定 3.5px）常時表示。
  - **グレイズ（かすり）判定**: 弾の極限回避でスコアとグレイズ数が上昇。
  - **3フェーズの大型ボス戦**（「PHANTOM AURA - CHRONO WEAVER」）: 旋回スパイラル弾、幾何学花弁弾、発狂弾幕カーテン。
  - **アイテム自動回収ライン (POC: Point of Collection)**: 画面上部への移動で全アイテム自動吸引。
- **純粋なWeb技術による超軽量・高速動作**:
  - 外部ライブラリ・画像・音声ファイルへの依存ゼロ（HTML5 Canvas 2D + Web Audio API）。
  - 事前レンダリングされた発光スプライトとオブジェクトプールにより、スマホ環境でも1000発以上の弾幕を安定した60FPSで描画。
  - Web Audio APIのオシレータ・ノイズ合成によるサイバーパンク調のBGMと効果音。
- **PC操作にも完全対応**:
  - キーボード: 矢印キー / WASD（移動）、Shift（低速モード）、X / スペース（ボム）、Z（ショット）。
  - マウス: ドラッグ移動、右クリックボム。

## 🕹️ 操作方法

### スマートフォン
| 操作 | アクション |
| :--- | :--- |
| **画面スワイプ / ドラッグ** | 自機の相対移動（指の位置に依存せず追従） |
| **自動** | ショット発射 |
| **BOMB ボタン** | ボム発動（消弾 + 無敵 + 得点アイテム化） |
| **SLOW ボタン** | 精密回避モード（移動速度低下） |

### パソコン
| キー / 操作 | アクション |
| :--- | :--- |
| **矢印キー / [W][A][S][D]** | 自機移動 |
| **[Shift]** | 低速精密移動 |
| **[X] / [Space]** | ボム発動 |
| **[Z]** | ショット（押しっぱなし可） |
| **マウスクリック＆ドラッグ** | 自機の相対移動（右クリックでボム） |
| **[P] / [Esc]** | ポーズ |
